# ContextPack Profiles

ContextPack includes built-in profiles for different AI workflows.

| Profile | Best for |
| --- | --- |
| balanced | Everyday code review and assistance |
| compact | Small chats with limited context space |
| deep | Architecture and full project review |
| bugfix | Debugging and regression analysis |
| docs | Documentation improvement |
| security | Safety-focused repository review |

Example:

```bash
contextpack build . --profile compact --output CONTEXT.md
```
