# Output Files

ContextPack can generate several output types.

- `CONTEXT.md` - AI-ready repository bundle
- `context-index.md` - file and language index
- `context-manifest.json` - file hashes and metadata
- `context-report.md` - scan summary
- `context-report.html` - browser-friendly report
- `context-chunks/` - split bundles for smaller AI chats
